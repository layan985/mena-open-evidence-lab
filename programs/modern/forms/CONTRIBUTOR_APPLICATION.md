- Full name
- University

## Research fit
- Rank up to three pods you want to join.
- What research question about the MENA region would you most like to answer? (150 words max)
- Which tools can you currently use? Python / R / Stata / SQL / Git / LaTeX / other
- Link one example of analytical, coding, research, or writing work.

## Mini research task
Choose a public dataset relevant to the MENA region and submit a repository containing:
1. source citation and retrieval date
2. raw-to-clean script
3. five clearly named variables
4. documented transformations
5. one visualization
6. README explaining how to reproduce the output

## Commitment
Can you contribute approximately 4–6 hours per week from September 2026 through January 2027? Do you agree that credit depends on actual documented work?

## Fellowship interest
Would you like to be considered for one of 11 MODERN Research Fellowship places? Why? (100 words max)

Do not request unnecessary sensitive personal data. Selection should be based on submitted work, reliability signals, and research fit.
