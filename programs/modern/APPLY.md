# Apply — MODERN Cohort 01

MODERN is recruiting a small founding contributor group for the September 2026 production sprint.

This is not an honorary membership program. Applicants are evaluated on a small reproducibility task and research fit. Contributor status begins only after a substantive, reviewable contribution is merged or included in a validated public release.

## Priority founding roles

- Labor Markets
- Firms + AI
- Financial Markets
- Public Policy + Data
- Research Engineering

Other pod interests are welcome, but the initial intake prioritizes these five execution gaps.

## Application window

**Open:** 8 August 2026  
**Priority review:** applications received by 22 August 2026  
**Initial onboarding:** late August 2026  

Applications may remain open after the priority date if production gaps remain.

## What to submit

Email **layanoraidi@gmail.com** with subject:

`MODERN Cohort 01 — [Your Name] — [Primary Role]`

Include:
1. Full name
2. University / organization and program or role
3. Country / time zone
4. GitHub profile, portfolio, or one sample of analytical work
5. Up to three MODERN pods/roles of interest
6. A short answer: *What MENA research question would you most like to make easier to answer?* (150 words max)
7. Current tools: Python / R / Stata / SQL / Git / LaTeX / other
8. Whether you can contribute roughly 4–6 hours/week during the initial production sprint
9. Whether you want to be considered for the MODERN Research Fellowship track

Do not send passports, national IDs, health information, bank information, or other unnecessary sensitive data.

## Mini reproducibility task

Choose one **small public dataset or table relevant to the MENA region** and create a public GitHub repository containing:

1. original source citation and retrieval date
2. original/raw file when lawful to redistribute, otherwise a retrieval script or clear source instructions
3. raw-to-clean script
4. at least five clearly named variables
5. documented transformations
6. one validation check
7. one visualization or summary table
8. README with exact reproduction instructions

The task should be small enough for another person to inspect in under 30 minutes. We prefer careful, boring work over ambitious but unverifiable work.

## How applications are evaluated

Reviewers use [`SELECTION_RUBRIC.md`](SELECTION_RUBRIC.md). Strong signals include:
- exact provenance
- code that runs
- sound judgment about missing or incomparable data
- clear documentation
- honest limitations
- reliability and scope discipline

University prestige is not a scoring category.

## What accepted applicants receive

Acceptance gives access to onboarding and a scoped production assignment. It does **not** immediately create public contributor credit.

Verified contributors can receive:
- public contribution credit on releases
- CRediT-style role attribution where applicable
- eligibility for the 11-place Research Fellowship track
- methods/reproducibility review from the network
- workshop access
- eligibility to lead a pod or release after demonstrating reliability

## Privacy

Applicant details and decisions are kept out of the public repository. Only aggregate application statistics may be published. Public contributor identity is added only after consent and a verified contribution.
