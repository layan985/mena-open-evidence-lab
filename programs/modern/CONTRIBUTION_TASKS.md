# Bounded Contribution Tasks

## 1. Observatory v0.3 independent source audit

**Object:** 48-row official-price release candidate.  
**Minimum task:** rerun the clean-room pipeline, check at least one official release from each of five institutions, include one conflict-affected Palestinian pair, and publish the completed audit template plus discrepancies.  
**Credit if accepted:** Independent Reproducibility Reviewer; co-authorship only if the contribution materially changes the dataset or method and meets authorship norms.

## 2. AI × Labor blinded second coding

**Object:** frozen 16-passage sample with founder labels removed.  
**Minimum task:** read the public codebook, code every passage independently before seeing founder labels, return the completed file, and permit publication of agreement statistics and discrepancies.  
**Credit if accepted:** Independent Second Coder / Validation Contributor.

## 3. Workshop 001 blind reproduction

**Object:** synthetic 56-row DiD teaching package.  
**Minimum task:** use only the public folder to recover 56 rows, four means, and the 2.6679167 result; log friction and permit an anonymized pass/discrepancy count.  
**Credit if accepted:** Reproduction Participant; co-facilitator credit requires an actual facilitation role in the live session.

## Rules for all three

- The task must be completed by a real, identifiable person.
- Relevant conflicts or relationships are disclosed.
- Discrepancies are recorded before repair.
- Private feedback alone does not create public contributor status unless the contributor agrees to attribution and the work is incorporated into an auditable artifact.
- Titles are not offered before the work is accepted.
