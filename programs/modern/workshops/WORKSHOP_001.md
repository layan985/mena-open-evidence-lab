# Workshop 001 — Reproduce an Economics Result from Raw Data

**Format:** 90 minutes  
**Audience:** undergraduate and graduate students, research assistants, early-career researchers  
**Mode:** live online or hybrid  
**Instructor:** MENA Open Data & Evidence Lab / MODERN

## Learning objective
By the end of the workshop, a participant should be able to take a small public dataset from authoritative source to a reproducible descriptive or regression result with documented provenance, transformations, validation checks, and a clean research output.

## Agenda

### 0–10 min — Why replication fails
- broken source links
- undocumented manual edits
- inconsistent identifiers
- hidden exclusions
- ambiguous units
- software/environment mismatch

### 10–25 min — Inspect the source
- identify authoritative publisher
- record retrieval date and source URL
- inspect terms / licensing
- freeze the raw input
- write a provenance note

### 25–45 min — Raw to clean
- parse and standardize names
- handle missingness explicitly
- document units
- test duplicate keys
- create a clean analysis table

### 45–60 min — Reproduce one result
- compute the target statistic or fit the target model
- compare to expected output
- document any discrepancy rather than hiding it

### 60–75 min — Break it deliberately
- change one sample rule
- change one transformation
- change one inference choice where applicable
- observe what moves and what does not

### 75–85 min — Package the research object
Required files:
- README
- source/provenance note
- raw-to-clean script
- analysis script/notebook
- validation checks
- output table/figure
- environment instructions

### 85–90 min — Independent rerun challenge
Participants exchange repositories and attempt a clean rerun without verbal help.

## Exercise

Use a small lawfully accessible public economic dataset. The exercise must be selected only after redistribution/licensing status is documented.

Participants must produce:
1. one clean table
2. one figure or model result
3. one validation report
4. one README command that reproduces the output
5. one paragraph documenting limitations

## Completion evidence
The workshop counts in MODERN metrics only after:
- agenda and materials are archived
- registration/attendance evidence exists
- exercise materials are available
- at least one participant completes or attempts the independent rerun

## Recording
Record only with participant consent. Publication of names or attendance lists requires explicit permission; aggregate attendance is sufficient for public reporting.
