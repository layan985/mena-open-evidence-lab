# Impact Metrics and Counting Rules

These definitions prevent résumé inflation.

## Contributors — target 23
Count a person only after a merged research contribution, validated release contribution, completed audit, or workshop instructional contribution.

## Universities — target 7
Count a university only if at least one qualifying contributor is affiliated with it during the cohort period.

## Datasets — target 18
Count only public releases passing `DATASET_STANDARD.md`.

## Observations — target 42,000+
Count canonical processed analytical rows from released empirical datasets; do not double-count mirrors or versions.

## Workshops — target 6
Count only workshops with materials and attendance evidence.

## Researchers trained — target 11
Count only fellows satisfying all completion requirements.

## Institutional partners — target 3
Count only documented collaborations with a concrete deliverable.

## Policy users — target 2
Count only organizations with documented substantive use.

The Research Coordinator updates registries weekly; the Research Director signs off monthly. The final February 2027 impact report should include an evidence appendix.
