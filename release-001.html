What changes when the source itself is part of the research question?

Release 001 formalizes seven flagship programmes around prices, labour measurement, AI adoption, statistical vintages, procurement, release timing and evidence lineage. The first new forensic result documents language-dependent timestamps in Jordan's public statistical file archive without treating those timestamps as equivalent to first dissemination in every official channel.

Release Forensics 001

Jordan Department of Statistics public-file archive · matched Arabic/English pairs · audit retrieved 17 August 2026.

The public evidence trail can have a language timestamp.

For four matched official-file pairs, the English file's archive timestamp followed the Arabic file's timestamp by 3, 6, 13 and 16 calendar days. This is a property of the visible archive records we audited. It is not evidence that English-language users had no access to the statistic through any other official channel during the gap.

Research standard for this release

Release 001 distinguishes directly observed archive facts from inference. File timestamps are recorded as file timestamps. A public-web publication date is not silently relabelled as an official first-dissemination time. A methodological description is not treated as proof of implementation in every historical period. Missing verification remains missing rather than becoming a zero.
