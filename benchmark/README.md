# MENA-EconBench

A planned bilingual benchmark for economic-language models.

## Tasks
1. economic sentiment,
2. inflation concern,
3. monetary-policy stance,
4. financial stress,
5. economic uncertainty,
6. market-moving event classification.

Each task should include Arabic and English examples where feasible, documented annotation rules, fixed train/validation/test splits, naive and strong baselines, fixed metrics, and hidden test labels for leaderboard use.

The benchmark must not be released until label quality and inter-annotator agreement are reported.
