Seven evidence objects in every room

Country coverage is only called live once the page exposes the evidence architecture, not merely a country name and a chart.

01

Current dashboard

Values carry reference period, release date where preserved, primary source, vintage and definition. Incomplete values are visibly withheld.

02

Official source map

Statistical office, central bank, fiscal, trade, labour and country-specific evidence producers.

03

Measurement notes

Geography, nationality, denominator, survey status, instrument, base year, language and other comparability constraints.

04

Release & revision ledger

First released state, current preserved state and structural or statistical revision flags.

05

Original findings

Two or more small findings whose claims are traceable back to the source architecture.

06–07

Program + evidence status

Named research objects and operational evidence-status fields without decorative completion percentages.
