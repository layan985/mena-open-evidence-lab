# Research Release Gate

A MENA Evidence Lab result is not ready for a headline merely because it is interesting.

## Evidence gate

- [ ] Every headline number resolves to a primary or clearly identified official source.
- [ ] Source files or stable source records are preserved where legally/technically possible.
- [ ] Release dates and reference periods are explicit.
- [ ] Calculations reproduce from the released input manifest.
- [ ] Rounding differences are documented rather than silently reconciled.

## Comparability gate

- [ ] Indicator definitions and denominators are documented.
- [ ] Methodology/base-year regimes are identified.
- [ ] Routine revisions are separated from methodology shocks.
- [ ] Any loss of comparability is coded explicitly.
- [ ] Cross-country comparisons use genuinely comparable objects or carry a visible limitation.

## Statistical gate

- [ ] Sample construction was specified before looking for the desired outcome where selection could bias the result.
- [ ] Small samples are presented as cases, not population-level rankings.
- [ ] Uncertainty is reported where an estimand supports it.
- [ ] At least one hostile but defensible specification/check has been run for material empirical conclusions.
- [ ] Null or contrary results are retained.

## Validation gate

- [ ] A second person or independent procedure checks every flagship headline calculation.
- [ ] At least a sample of larger releases receives non-author reproduction/validation.
- [ ] Disagreements and corrections are logged.
- [ ] Validation state is visible in machine-readable output where applicable.

## Claim gate

- [ ] The headline says exactly what the evidence supports.
- [ ] A statistical revision is not called an error unless evidence establishes an error.
- [ ] A methodology change is not framed as manipulation without separate evidence.
- [ ] A changed historical estimate is not described as the underlying past changing.
- [ ] Causal language is used only with an identification strategy that supports it.

## Commercial-independence gate

- [ ] Sponsor/client involvement and review rights are disclosed when relevant.
- [ ] Public research conclusions are not changed to satisfy a buyer.
- [ ] Any restricted evidence required for a commissioned conclusion is clearly distinguished from public evidence.

## Release decision

If any material gate fails, publish a narrower result, a case note, or a documented unresolved question instead of forcing a stronger claim.
