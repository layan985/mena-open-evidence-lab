Permanent record

Old versions remain part of the evidence.

The archive registry records DOI state, version, repository location, recorded commit identifiers where available, and whether an object has reached permanent external archival status.

Archiving rule

Published versions are never silently overwritten. Superseded objects remain addressable. A withdrawn object remains discoverable with its withdrawal notice. A DOI is never shown before it has actually been issued.
