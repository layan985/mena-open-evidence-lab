Open contribution protocol

Found a revision that changes the story?

Contribute a candidate case or independently reproduce an existing one. Attribution is attached to the verification artifact, not to vague support or endorsement.

Four-step protocol

01

Identify the object

Country, indicator, reference period, unit and the exact qualitative conclusion at stake.

02

Supply both vintages

Earlier and later comparable official values with direct primary-source URLs.

03

Explain comparability

State why the two observations refer to the same underlying object despite any methodological change.

04

Classify the reversal

Sign, ranking, threshold, or acceleration/deceleration. Large revisions without a boundary crossing do not qualify.

Minimal submission template

Copy this into a GitHub issue or email. Keep it boring and auditable.

Country: Indicator: Reference period: Unit: Earlier official value: Earlier official source URL: Later official value: Later official source URL: Reversal class: sign / ranking / threshold / direction Boundary crossed: Why the vintages are comparable: Methodology event, if any: Claim boundary: Your name and affiliation for attribution (optional):

Independent reproduction

You do not need to endorse the Lab or the interpretation. The question is narrower: can you reproduce the source chain and classification?

Pass

Source pair reproduces

The reported earlier/later values match the cited primary sources, and the reversal classification follows mechanically from the stated rule.

Fail / query

Something does not reproduce

Report the discrepancy. Failed reproduction is useful evidence and remains part of the validation trail.
