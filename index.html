03 / Validation

Four states. Never one vague badge.

The Lab separates work that has been checked internally from work that has been challenged by somebody outside the Lab.

01 / INTERNAL QA

Tests and founder reruns

Useful for finding mistakes. Not counted as independent evidence.

02 / SOURCE AUDIT

Capture and coding review

Checks that the public record was read, linked and transformed correctly.

03 / REPRODUCTION

Outside execution

Requires an external person to rebuild the object with a reviewable record.

04 / EXTERNAL USE

Attributable application

Counted only when dataset, user, institution, use, evidence and date can be recorded.

Current rule: no output is described as independently reproduced until an outside reproduction record exists. Open states remain visible rather than being converted into marketing language.
04 / Independent challenge

Other people’s fingerprints belong on the work.

The next credibility gains come from bounded outside work: source audits, second coding, clean-environment reproductions and methods review. The contribution routes are public so review can be evidenced rather than implied.
