Build something that can survive its founder.

Targets: 7 universities; 25–40 validated contributors; 12–18 serious DOI-backed releases; 100k+ standardized observations; 10 independent reproducibility audits; 6 workshops; 3 faculty advisers; 3 institutional collaborations; 2 documented policy/research uses; one external code maintainer; one conference presentation; one methods/data paper; and a public API with outside users.

These are targets, not current claims.
