# Evidence Request Template

Use for statistical offices and source custodians.

## Request structure

**Object:** exact indicator / table / release.  
**Reference period:** exact year/quarter/month.  
**Historical cutoff:** release date or pre-methodology-change period needed.  
**What is already held:** later/current source, methodology note or partial archive.  
**What is missing:** exact file, table, release or metadata field.  
**Research use:** reconstruct the publicly knowable historical information set; preserve revision/methodology history.  
**Verification ask:** source location or confirmation/correction of the release chain.

## Rule

Never ask an NSO to 'send all historical data'. Make the missing evidence object small enough that a statistician can route or answer it quickly.
