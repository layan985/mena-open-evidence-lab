# Evidence-Led Publication Pipeline

## Rule

One verified research object should generate the communication. Do not manufacture a post first and search for evidence afterward.

## Release sequence

### 1. Evidence object
Primary releases, machine-readable values, source hashes, methodology metadata and calculation.

### 2. Evidence note
A short page stating:
- what changed;
- exact vintages being compared;
- why the comparison is valid;
- what cannot be concluded;
- links to sources/data/code.

### 3. Visual
One chart or table that can be understood without decorative context. Show the unit, period, source vintage and revision/methodology boundary.

### 4. Public post
Structure:
- first sentence = empirical fact;
- second = why it is surprising/useful;
- third = what was tested;
- fourth = claim boundary;
- link = evidence object.

### 5. Technical distribution
Send the methods/data object to people who can critique, reproduce or extend it.

### 6. Commercial distribution
Send the failure mode to people whose work is exposed to it, with a bounded diagnostic offer.

## Strong upcoming post candidates

1. **Saudi Arabia's 2023 GDP changed sign across official vintages.** Already evidence-backed; lead into why historical information sets matter.
2. **Can you recover the number an analyst actually saw?** First Archive Reconstructability case comparison once multiple cases are verified.
3. **When does a revision become a different measurement system?** Explain routine revision versus methodology shock with a real documented example.
4. **The Claim Survival experiment.** Publish the protocol before results so the audience can see the rules were not invented after discovering reversals.
5. **A null result.** Deliberately publish a case where a large-looking revision does not alter the substantive conclusion, proving the Lab is not optimizing for drama.

## Avoid

- unsupported regional rankings;
- generic founder inspiration;
- 'data is the new oil' language;
- claiming statistical offices are wrong because a release was revised;
- fake precision from small samples;
- AI-generated decorative charts without source-level evidence.
