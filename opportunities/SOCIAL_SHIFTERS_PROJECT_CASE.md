# Social Shifters 2026 — MENA Evidence Lab Project Case

## One-line description

Open evidence infrastructure that preserves the historical record of MENA official statistics so researchers, journalists and decision-makers can see what a number meant when it was published, how it changed, and whether later revisions alter conclusions drawn from it.

## Problem

Economic decisions are often evaluated using today's version of yesterday's data. Official GDP, labour, inflation and other statistics can be revised, rebased or redefined after first publication, while older releases may become difficult to retrieve. That creates a reproducibility problem: researchers can lose the ability to reconstruct the information available when a decision or public claim was originally made.

The problem is acute when historical releases, machine-readable data, methodology notes and comparable definitions are distributed across changing websites and formats.

## Intervention

MENA Evidence Lab preserves official releases as time-stamped evidence objects rather than allowing later values to overwrite the historical record. Each observation can be linked to its release date, vintage, methodology regime, source record, transformation and validation state.

Current infrastructure includes:

- MENA Vintage Vault for historical releases and revisions;
- MENA Data Revision Atlas specification covering first release → revision → current value;
- Methodology Shock Registry for rebasing, classification and coverage changes;
- public provenance and validation standards;
- reproducible evidence notes and machine-readable packages.

The next layer measures statistical revision exposure and historical archive recoverability. A Claim Survival pilot will test whether dated economic conclusions remain true under later comparable official vintages.

## Existing proof

A first verified case reconstructs Saudi Arabia's reported 2023 real-GDP growth before and after a comprehensive national-accounts revision: the preserved pre-revision official vintage reports −0.8%, while the later revised accounts report +0.5%. The Lab treats this as a measurement event and preserves the source chain rather than claiming the economy itself changed retrospectively.

Only verified usage, contribution and impact counts should be added to an application.

## Beneficiaries

- students and researchers who need reproducible historical data;
- journalists comparing regional economic statistics;
- public-interest organizations using regional evidence;
- statistical-system practitioners interested in archive quality;
- analysts whose historical evaluations may be contaminated by latest-vintage data.

## Public value

Public accountability depends on reconstructing the evidence available when a decision or claim was made. If only the latest number survives, retrospective analysis can accidentally use information that did not exist at the time. Preserving release history makes evidence more reproducible and contestable.

## Differentiation

The Lab does not merely republish current indicators. It treats release timing, historical vintages, methodology changes, missing archives and provenance as part of the empirical object.

It also keeps three distinct problems separate:

1. routine revisions;
2. comprehensive methodology changes;
3. inability to recover the historical record.

That distinction avoids misrepresenting legitimate statistical improvements as errors.

## 12-month plan

1. Reconstruct high-quality vintage chains for an initial set of MENA macroeconomic series.
2. Publish the Measurement Stability Framework and a first cross-country evidence report.
3. Run a pre-registered 100-claim Claim Survival pilot.
4. Obtain independent checks on a sample of cases and publish disagreements/corrections.
5. Improve machine-readable access to preserved releases and provenance records.
6. Run practical reproduction sessions for students and early-career researchers.
7. Build technical partnerships that improve archive access and validation.

## Potential use of grant funding

Subject to the funder's permitted cost categories:

- archive acquisition and preservation;
- research assistance for double extraction/coding and validation;
- data engineering and automated QA;
- hosting/storage and stable public distribution;
- independent methods review;
- documentation and accessible visualization;
- practical training and reproduction sessions.

## Impact measures

- historical releases preserved;
- observations with complete provenance;
- archive gaps documented;
- cases independently checked;
- external data uses/downloads/citations;
- completed reproduction exercises;
- corrections resolved;
- institutional requests for data or methods reuse.

## Sustainability

The Lab uses a public-core / paid-application model. Public datasets, methods and evidence objects create reusable infrastructure and trust. Bounded commissioned work—historical information-set reconstruction, statistical-revision audits, provenance audits and reproducibility work—funds specialist applications of those methods.

The goal is not to paywall the public record. Paid work should help sustain infrastructure that keeps the public record inspectable.

## Closing proposition

If an economic number shaped a decision in the region, an independent researcher should be able to recover what the number was, what it meant, when it became knowable and how it later changed.
