# MODE Founding Researcher Challenge

Applicants complete a small evidence task rather than a generic motivation essay.

## Task 1 — Source trace
Locate the original official source for one numeric economic claim and document the exact table/release/period.

## Task 2 — Bilingual validation
Compare Arabic and English statements referring to the same event and identify semantic or quantitative mismatches.

## Task 3 — Indicator reproduction
Reproduce one supplied indicator from raw observations and submit code/output.

## Task 4 — Uncertainty note
Explain what cannot safely be inferred from the evidence.

## Scoring
- Analytical accuracy — 40%
- Reproducibility — 25%
- Documentation — 20%
- Methodological judgment — 15%
