# Claim Badge Standard

Every material public number must carry one or more of the following labels. No softer substitute vocabulary is permitted.

| Badge | Meaning |
| --- | --- |
| `OFFICIAL SOURCE` | Directly published by an official institution or regulator. |
| `REAL PUBLIC DATA` | Observed, externally published public data. |
| `PROVIDER TEST` | Executed against a provider-controlled test or sandbox environment. |
| `SYNTHETIC` | Generated data used for method/workflow validation. |
| `RANDOMIZED SYNTHETIC` | Seeded randomized experiment over generated data. |
| `PRODUCTION CLIENT DATA` | Real client/institutional data used with explicit permission and disclosure boundaries. |
| `EXTERNAL REVIEW` | Documented outside methodological or code review. |
| `INDEPENDENT REPRODUCTION` | Documented outside rerun reproducing a specified result. |
| `PENDING VALIDATION` | Evidence required for the claim does not yet exist or is not yet disclosed. |

## Display contract

Every headline number must expose: **CLAIM → NUMBER → BADGE → SOURCE → DATE/WINDOW → N → FILTER → TRANSFORMATION/CODE → REPRODUCIBLE? → LIMITATION → STATUS**.

A number without that trail is not a Lab claim. Internal tests, founder reruns, plans, invitations, applications and conversations do not become external validation by wording.
