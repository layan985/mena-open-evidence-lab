Trust is release-specific.

The Lab does not use one institutional credibility badge. Each research object has its own producer, verification requirement, reviewer state and evidence trail. Internal QA can move an object to release-candidate status. Only attributable outside work can move it into an independent-validation state.

01 / Internal QAProducer-owned

Tests, reruns, source checks and documentation performed by the producing team.

02 / Independent verificationDifferent person

Source audit, blinded second coding or methods challenge by someone other than the primary producer.

03 / ReproductionOutside execution

Clean-environment reconstruction with a reviewable result and discrepancy record.

04 / External useAttributable use

Named user or institution, concrete use, evidence and date.

Counting rule

An independent validation record requires a person other than the primary producer to complete the defined verification task and leave evidence that can be reviewed. A founder rerun, code review by the same producer, or informal comment does not satisfy that rule.

No empty trust signals

The Lab does not list reviewer logos, advisor names, partner names or institutional affiliations until those relationships are real, accepted and attributable. Open assignments are shown as open rather than being converted into implied endorsement.
