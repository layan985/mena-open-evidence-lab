Core query

What was actually knowable on date d?

MENA-RTD defines the historical information set as the collection of source-verified observations publicly available by a chosen cutoff. The system is designed to answer a question latest-vintage databases usually cannot: whether an observation existed yet, which vintage existed, and under which methodology.
