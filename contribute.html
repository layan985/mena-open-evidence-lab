Review protocol

What makes an external review count.

01 / IDENTIFIABLE

A real person completes the work and can be attributed in the review record unless a documented safety reason requires limited public identification.

02 / INDEPENDENT

The reviewer is not the primary producer of the object being validated and relevant conflicts are disclosed.

03 / REVIEWABLE

The work leaves an artifact: audit sheet, coding file, reproduction log, discrepancy record or methods memorandum.

04 / STATE-CHANGING

The result maps to a defined validation field. Informal praise and private comments do not change release status.

Recognition

Accepted work records the contributor, contribution type, affected artifact, date and evidence location. Authorship follows documented intellectual contribution; review alone is not authorship. Advisory appointment is also separate and is listed only after explicit acceptance.

Working materials

Reviewers can use the bounded task specification, reviewer packet, validation dashboard and machine-readable assignment register. Open a repository issue before substantial work so scope and evidence requirements are frozen before review begins.

Advisory appointments

Methods & Reproducibility, Regional Data, and Open Research & Governance remain open advisory roles. They are not used as substitute evidence for release-level review.

External review changes release state only when attributable evidence exists.
