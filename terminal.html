Evidence Terminal · public prototype

Find the number. Then inspect where it came from.

The Terminal is the Lab’s provenance interface: value or object, entity, period, release timing, vintage, revision state, source, retrieval timestamp, transformation, license, source hash, code commit and validation state belong in one record.

Prototype boundary. This interface currently searches public Lab release objects rather than pretending a full regional indicator warehouse already exists. The production specification is public and the data contract expands as source-bound indicator records are released.

Required record

The interface is designed around the fields requested in the Lab’s data contract.

Identity

indicator/object · entity · value · unit · reference period

Release

release date · vintage · revision status · publisher

Provenance

source · retrieval timestamp · transformation · source hash

Reproducibility

code commit · license · validation status · caveat
