## Report contract

Every released report page exposes these controls:

- **DOWNLOAD PDF** — only when an actual frozen PDF exists.
- **DOWNLOAD DATA** — exact release data or a documented public extract.
- **VIEW METHODOLOGY** — inclusion/exclusion, transformation and identification rules.
- **VIEW SOURCES** — official URLs, access dates, hashes where available.
- **VIEW CODE** — exact scripts/notebooks/config used for the release.
- **VIEW QA** — checks, failures, warnings, missingness and known anomalies.
- **VIEW LIMITATIONS** — explicit failure boundaries and missing evidence.

If one of these objects does not yet exist, the interface says `PENDING VALIDATION`; it does not point to a decorative placeholder.
