# Provenance policy

Every released observation must remain traceable to a source.

## Minimum provenance
- source institution,
- source URL,
- retrieval date,
- reference period,
- release date where available,
- source language,
- transformation notes,
- verification status.

## Verification
A record may be marked `verified` only after a second person or independent retrieval path confirms the value and source metadata.

## Corrections
Corrections are additive and versioned. A corrected release must preserve a public changelog identifying the affected observation IDs, prior values, corrected values, reason, date, and reviewer. Public history is never silently overwritten.
