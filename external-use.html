External-use ledger

Use is evidence. It is not the same thing as validation.

The Lab currently reports 5–10 external users of Lab datasets or code, 50 dataset downloads and two attributable client/research-user quotes. Public identities and output-level use records are published only where disclosure rights allow.

Attributable use records

Where publication rights permit, use records identify the output, user or institution, use category, date and supporting evidence. Confidential use remains in aggregate institutional counts rather than being fabricated into public identities.

Canonical institutional totals: data/institutional-metrics.json

Counting rule

External use is counted only when the Lab has a concrete use record. An external user is not automatically a reviewer; a testimonial is not a reproduction; and a reproduction is not inferred from a download.
