Release discipline

No country scores yet.

The rubric is public now; the league table is not. A regional release requires coder calibration, evidence retention, explicit handling of missing evidence and a correction route for audited institutions.

This protects the project from turning website convenience into a fake judgment about statistical competence.

What the first full release will contain

Institution × product-family audits, dimension-level scores, exact evidence links, retrieval dates, coder agreement, correction history and reproducible aggregation. Product families will be separated where infrastructure differs materially.

Why this matters

Researchers routinely spend invisible time finding old releases, reconstructing definitions and discovering that a link now points to a newer file. That friction changes which questions can be reproduced and which historical information sets can be reconstructed.
