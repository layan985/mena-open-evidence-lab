# Why the Lab still shows zeros

I built the application form, tracking tables, workshop exercise, and review templates before anyone had joined. That made the repository look further along than the work itself.

I am separating setup from outcomes:

- an application route is not a contributor;
- a workshop folder is not a delivered workshop;
- an unsent email draft is not outreach and definitely not a partnership;
- an author-run test is not an independent reproduction;
- a candidate dataset is not a Lab release.

The tracking files therefore stay at zero until an event actually happens and can be linked to a specific contribution, date, or release. The next meaningful change should be one checked data contribution or one delivered workshop, not another planning document.
